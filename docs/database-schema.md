# Database Schema - Supabase (PostgreSQL)

- **profiles:** User accounts, roles (`customer`, `admin`, `trip_leader`), phone, and spending metrics.
- **categories:** Experience categories (Day Trips, Beach Getaways, Cultural Tours, Special Events)[cite: 1].
- **experiences:** Trips, dates, pricing in EGP, meeting points, and available seats[cite: 1].
- **bookings:** Booking records, attendee info, payment status, receipt URLs, and QR payloads[cite: 1].
